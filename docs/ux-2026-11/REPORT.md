# Core + Modern · mobile registry and release audit

**Candidate tested, not deployed.** This checkpoint covers finding a horse, recovering from failed reads, navigating the Modern phone shell, distinguishing a newsroom outage from an empty feed, and reaching real registration. It is not certification of all routes, permissions, browsers or data providers.

## What changed

| Journey | Core (Heritage) | Modern |
|---|---|---|
| Find a horse | Fixed the portalled Columns picker: a checkbox tap no longer counts as an outside click; focus enters the picker, Escape returns focus, scrolling within it does not dismiss it. | Show the first live browse page without waiting for seven optional requests. Do not display sample horses or a fictional registry total in the Explorer during an outage. Retry in place. Abort superseded searches; distinguish a full-registry search failure from zero matches. |
| Read a profile | Localized horse loading text, accessible status, and retry on horse/person read failures. | Public profile/pedigree reads still need a full field-by-field parity pass. |
| Navigate on a phone | Preserved the existing dock, compact registry modes and keyboard controls. | More drawer removes hidden controls from focus order, isolates the background, supports Escape and restores focus. Kept readable landscape labels and ≥44px bottom controls; use safe-area insets and respect reduced motion. |
| Register | Existing permission-checked submission workflow remains authoritative. | Replaced the locally generated “submitted” reference in the registry entry path with a link to the real Core desk. No form is submitted by visiting the link. This is delegated parity, not a second write implementation. |
| Read news | Existing newsroom service unchanged. | Only published content is shown; outage → retry, empty published feed → empty state. Filters follow the returned kinds, not demo categories. |
| Load the app | Shared assets and unrelated skins unchanged. | Same-origin fonts; ten secondary pages are loaded on demand. The entry script **plus declared JS preloads** fell from 924,699 to 524,828 bytes (−43%), or 272,309 to 170,180 bytes with gzip (−38%). Not a claim about real-world latency or total session bytes. |

## Release blockers and next work, in order

1. **Restore CI and reconcile deployment paths.** The manual production workflow requires exact-revision approval + real PostgreSQL checks; a separate main-push workflow calls Wrangler directly after typecheck/build. They do not enforce the same gates. The planning commit triggered CI and auto-deploy; neither job started because GitHub reported a billing or spending-limit problem. The UI changes belong on a review branch rather than silently going live when billing resumes. Latest verified Cloudflare version: `0bc6d013-6ddf-4fc7-a0fb-d74c6eb28cd0` at 100%. No release approval or CI variable changed.
2. **Resolve the equine microchip visibility contract.** Fixed two stale lockfile version fields without changing dependencies. `validate:platform` still fails: `src/db/types.ts` documents a later owner instruction allowing the horse chip as an opt-in public column; `docs/DATA_VISIBILITY.md` and the contract validator classify it as privileged. An opt-in display is not access control. Resolve the intended audience across browse/detail/search/export and both DB adapters, test anonymous and privileged responses, then align the spec/test. Do not simply silence the check. This checkpoint neither broadens nor narrows access.
3. **Correct stale analytics before promising parity of statistics.** Inspect the snapshot generation receipt, source revision, refresh job and freshness threshold. Do not show zeroes or old demo totals in place of an unavailable snapshot. Verify both clients against the same completed snapshot and keep an as-of label when stale.
4. **Next UI/data slice: same horse and same people end to end.** Core uses server paging and sorting; Modern still hydrates a bounded slice (up to 800 records) and filters locally in several paths. Validate IDs and totals across search→horse→sire/dam→offspring→race→back. Replace default birth year/sex/coat/discipline sentinels with explicit unknowns across Modern cards/filters. In Modern's people directory, breeders are filtered after fetch but `loadMore` uses the filtered row count as its offset: use the backend cursor/unfiltered offset and test sparse pages. Check RLS/permission states for care and admin; never expose `source_catalog` review rows wholesale.
5. **Broader release qualification.** Test real API journeys with authorized non-production roles, D1 read fallback, deep links, slow/interrupted service, zoom, keyboard-only use, real iOS Safari and Android. Collect p75 LCP/INP/CLS in the field before calling the site fast on every phone. Ship the reviewed exact revision, then fetch both live shells, asset hashes, health and a known public record. Site rollback is restoring the prior Worker version; this patch needs no data rollback.

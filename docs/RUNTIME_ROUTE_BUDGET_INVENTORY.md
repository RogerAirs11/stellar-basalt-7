# Runtime Route Budget Inventory

Authoritative per-route budget inventory for the current API surface (post-package delta D04).
This document is machine-checked by `tools/validate-operational-inventories.mjs` (wired into `npm run check`),
which derives the current route set from `src/api/routes.ts` and fails if any route family/pattern is
missing here or a documented row no longer exists in source.

Recording conventions:

- **Path/pattern** uses the exact source token: a static `path === "..."` string or the regex literal
  from `path.match(/.../)`.
- **Limiter class** is the worker classification (`src/security/classify.ts`): `auth` (credential login plus environment-gated demo-admin login),
  `expensive` (breeding/relationship/pedigree/insights), `write` (state-changing non-expensive methods,
  D08), `public` (ordinary GET/HEAD/OPTIONS, 300/min/IP).
- **CPU** values are deliberately not invented: every row is marked `MEASURE-STAGING` until measured on
  real Cloudflare Free staging (D1 rows-read/rows-written + worker CPU per the Phase D plan).
- Query counts are the bounded steady-state shape (snapshot path vs live fallback), not speculative maxima.

## Notes

- `POST /api/auth/login` and the local/demo-only `POST /api/auth/demo-admin` shortcut use the `auth` limiter (10/min/IP).
  Only normal credential login additionally uses the per-account limiter (`ACCOUNT_RATE_LIMITER`, 5/min/account, hashed normalized email key, D10).
  Demo-admin login is disabled in production unless `ENABLE_DEMO_ADMIN_LOGIN=1` is explicitly set.
- Every 429 across all limiter classes carries `Retry-After: 60` centrally (D09).
- `/api/registry/export` is a privileged bounded synchronous read; it is deliberately **not** a
  whole-registry dump, and remains under the public read limiter with the hard 500-row ceiling.
- Snapshot-backed public responses use materialized values only while `registry_state` and source revision say they are current.
  Stale/missing snapshots take the exact live fallback; stale derived values are never presented as current operational facts.

### Registry role-name substring filters (efficiency candidate)

Owner/breeder/importer/passport substring filters retain their exact canonical `horse_people` + `people LIKE` predicate. When derived state is current and the term has at least three characters, `horse_role_search_trigram` first narrows candidate horse IDs. If `registry_state.analytics_stale=1`, that prefilter is bypassed automatically. This is a behavior-preserving read-amplification optimization, not a relaxed search path.

### Record matrix and fixes
Four real cases: Nilgun (#10100029, unknown sex and coat), Zibai Gnbd (#10109580, 2015 only), Frari (#10100000, missing birth and parent links), and Yami Minou (#20030, a disputed sire). The last remains canonical sire #6005 versus source claim #10107119; neither frontend should replace the registered parent with an unreviewed claim. Before-change mobile journeys covered each horse on both frontends in English and Persian. No source conflicts are automatically published or merged.

- Modern's record-ID helper no longer invents a chip, passport, studbook or UEL number for a live numeric ID. Registry cards no longer assign self-declared trust without evidence. Unknown sex is neutral in the list and pedigree. Geld. is recognized as gelding.
- Replaced sample mating recommendations with explicit parent selection and the platform's real pairing API. Local and remote choices are checked for the recorded adult sex; known deceased horses, foals, geldings, unknown sex and demo IDs cannot be selected. No automatic pair, simulated carrier status, or synthetic genotype prediction. An unavailable analysis is not zero. This is a pedigree comparison, not a statement of breeding fitness.
- Modern's Trust and Genetics tabs now read the same anonymous endpoints used by the platform, display only scoped issuer metadata/public test fields, and distinguish unavailable from successful empty results with a retry. Health/documents not fetched here are not reported as nonexistent. Offspring read failures are not zero offspring. Birthplace is no longer labelled as current location.
- Core now retains filly/colt meaning in translated profile labels and uses the same year-precision calendar formatter for plausible legacy Gregorian birth years as for typed dates. Modern localizes known breed terms with the shared encoder.

### Operations and remaining boundaries
Production analytics: the stored stale flag is **0**, and both snapshot revisions match the stored revision. However, 4,037 nondeleted restricted horses exist. The runtime explicitly rejects these unscoped snapshots when restricted records exist (`loadRuntimeSnapshot`); a timestamp refresh or toggling the flag cannot fix this. Build and validate a **public-active-only** snapshot and independently compare aggregates before changing this guard. The microchip policy conflict remains: R151's public, default-hidden equine ID projection vs `DATA_VISIBILITY.md` and its older validator. Do not bypass the guard or widen disclosure to make CI green.

Controlled fixture QA, responsive QA, production browser receipts, and live totals are separate artifacts. No claim of complete source access, private health coverage, or physical-device certification. Still to do: public-active analytics build and parity checks; resolve visibility policy; service-level collector supervision; treatment of source conflicts as scoped evidence for reviewers; authenticated care/admin journeys; accessibility on physical devices.
